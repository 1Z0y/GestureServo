# 手势控制舵机项目 (Gesture_control)

基于 STM32F103C8T6 的手势控制舵机系统，支持手势识别、舵机实时控制、动作录制回放、OLED 菜单配置及 Flash 断电保存。

## 性质
- 个人练习项目（用于学习）
  
## 硬件清单
- MCU：STM32F103C8T6
- 手势传感器：PAJ7620（I2C）
- 舵机：SG90（TIM3_CH3 PWM）
- 显示屏：OLED SSD1306 128x32（软件 I2C）
- 串口：CH343（USART1，115200）

## 功能特性
- 手势 → 角度映射：左 0°、右 180°、上/下 90°
- 多数表决滤波，窗口可调
- 状态机：控制 / 录制 / 回放 / 菜单
- 录制最多 10 帧，线性插值平滑回放
- 菜单可调滤波窗口、角度范围，配置存入 Flash
- OLED 实时显示状态，串口调试输出

## 软件架构
- `Core/Src/`：主程序、状态机、滤波、录制、运动、菜单、配置、驱动
- `Core/Inc/`：对应头文件
- `MDK-ARM/`：Keil 工程

## 如何编译
1. 用 Keil MDK 打开 `MDK-ARM/Gesture_control.uvprojx`
2. 编译并下载到 STM32F103C8T6
3. 按硬件清单接线，上电即可运行
